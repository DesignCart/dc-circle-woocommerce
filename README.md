# 🎨 DC Circle Theme for WooCommerce  

**DC Circle** is a **free, modern, and fully responsive WordPress theme** designed specifically for WooCommerce stores.  
Created by the **Design Cart** team, it combines clean design, flexibility, and performance — based on years of real e-commerce experience.

---

## 🚀 Key Features

- ✅ Fully compatible with **WooCommerce 8.x**
- ⚡ Lightweight and optimized for **Core Web Vitals**
- 🧩 Completely **customizable design**
- 🖼️ Separate banner images for **desktop and mobile**
- 🎨 **4 customizable button styles** with hover effects
- 🛒 Product carousels for **New arrivals, Promotions, Bestsellers, and Featured**
- 🧱 Extra **widget areas** between product sections and in the footer
- 🇵🇱 100% **Polish-language customizer interface**
- 🌍 Translation-ready and compatible with multilingual plugins

---

## 🧭 Installation Guide

1. Download the `dc-circle.zip` file from the **Releases** section or [Design Cart website](https://www.designcart.pl).  
2. In your WordPress dashboard, go to:  
   `Appearance → Themes → Add New → Upload Theme`.  
3. Upload the ZIP file and click **Install Now**.  
4. Once installed, click **Activate**.  
5. Make sure you have **WooCommerce** installed and activated.  
6. Go to:  
   `Appearance → Customize → DC Circle Settings`  
   to start configuring your theme.

## ⚙️ Configuration and Customization

### 🖼️ Banner Section
- Upload separate banner images for **desktop** and **mobile**.  
- Add a **custom H1 title**, **subtitle**, and **two CTA buttons** with your own text and links.

### 🎨 Color Settings
Full color control over all theme elements:  
- 4 independent **button styles** (background, text, hover)  
- Main text color  
- Footer background and font color  
- Link colors and hover effects  

### 🛒 Product Sliders
Enable or disable any of the following sections:  
- **New Arrivals**  
- **Promotions**  
- **Bestsellers**  
- **Featured**  

Each slider includes custom fields for:
- Section title  
- Product categories to display  

### 🧱 Widget Areas and Footer
Insert your own content using flexible widget zones:
- Below banner  
- Below new arrivals  
- Below promotions  
- Below bestsellers  
- Below featured products  
- Footer left / center / right columns  

### 🏠 Homepage Settings
Choose what appears on your front page:
- **Static page** (recommended for stores)  
- **Latest posts** (classic blog mode)
